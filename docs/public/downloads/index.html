Релизы gitflic-cli

Каждый релиз — это портативный tar.gz с bin/, lib/, package.json, инсталляторами. Без внешних зависимостей: распакуй → bash install.sh → используй gitflic.

  • gitflic-cli-0.3.2.tar.gz — bundled at release time

Артефакты собираются локально (scripts/build.mjs) и публикуются на этом же сайте через Timeweb Apps. Никакого S3, никакого CI-раннера. Подробнее — в разделе разработки.

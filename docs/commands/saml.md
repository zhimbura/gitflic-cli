# SAML SSO (`gitflic saml ...`)

> ⚠️ Admin-only. Code-only — не live-tested на self-hosted с SAML.

```bash
gitflic saml list                    # список SAML конфигураций
```

Конфигурация SAML-провайдеров (добавление/edit/delete) — только через Web UI в admin-панели. Нет публичного REST для mutations.

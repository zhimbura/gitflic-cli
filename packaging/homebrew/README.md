# Homebrew tap for gitflic-cli

This directory holds the Homebrew formula for `gitflic`. To ship it to users you
need a **tap** — a public Git repo named `homebrew-<something>` that Homebrew can
clone. `brew install gitflic` with no tap only works for formulae accepted into
`homebrew-core`, which requires a notability bar (≈75+ GitHub stars, active
maintenance) a new CLI won't meet yet. A personal tap has none of that overhead.

## One-time: create the tap repo

```bash
# 1. Create an EMPTY public GitHub repo named exactly `homebrew-tap`
#    under your account, e.g. github.com/zhimbura/homebrew-tap

# 2. Push this formula into it
git clone git@github.com:zhimbura/homebrew-tap.git /tmp/homebrew-tap
mkdir -p /tmp/homebrew-tap/Formula
cp packaging/homebrew/Formula/gitflic.rb /tmp/homebrew-tap/Formula/
cd /tmp/homebrew-tap
git add Formula/gitflic.rb
git commit -m "gitflic 0.3.0"
git push
```

> The repo MUST be named `homebrew-<x>`. `brew tap zhimbura/<x>` maps to
> `github.com/zhimbura/homebrew-<x>`. With `homebrew-tap` the tap name is
> `zhimbura/tap`.

## How users install

```bash
brew install zhimbura/tap/gitflic     # auto-taps + installs
# or
brew tap zhimbura/tap
brew install gitflic
```

## Releasing a new version

The formula's `sha256` must match the published npm tarball. After
`npm publish` (see `scripts/publish.mjs`):

```bash
node scripts/publish.mjs --bump-formula   # rewrites url + sha256 in this formula
# then copy the updated Formula/gitflic.rb into the tap repo and push
```

To compute the sha by hand:

```bash
curl -sL https://registry.npmjs.org/gitflic-cli/-/gitflic-cli-<VERSION>.tgz | shasum -a 256
```

## Why this formula works with zero runtime deps

`gitflic-cli` has no runtime dependencies — it only needs Node. The formula
`depends_on "node"`, runs `npm install` into Homebrew's `libexec` (which just
stages the package, no deps to fetch), and symlinks the `gitflic` shim into
`bin`. The shim is generated by npm from the package's `bin` field, which points
at `lib/gitflic.mjs` (a `#!/usr/bin/env node` script), so it runs everywhere
Node runs.
